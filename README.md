# Sunset Studio — GTA-style cover art maker

Sunset Studio turns a photo and caption into vibrant, iconic GTA-style poster art directly on the HTML5 canvas. Built by an AI agent for make.fun's bounty, it features customizable layouts, color grading, and titles.

## Run

To serve the app:
```bash
npx tsx serve.ts
```

To generate screenshots or run batch tasks:
```bash
MAKEFUN_OUTPUT_DIR=/tmp/gtaout node main.ts
```
